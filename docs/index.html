📖 新手指南

🏪
商店购买

点击底部商店的棋子卡片购买（需要金币）。长按卡片可查看详细属性。

💺
备战席 → 棋盘

先点击备战席上的棋子（变金色），再点棋盘上的空格放置。双击备战席棋子可出售。

⭐
升星系统

买3个相同棋子自动合成为2星（属性×1.8），3个2星合成3星（属性×3.2）！

⚔️
羁绊加成

棋盘上同羁绊棋子达到数量门槛时激活加成。如2个战士 → 攻击+15。

💰
经济管理

每回合基础+5金。存款每10金+1利息（最多+5）。连胜/连败也有额外收入。

📈
等级与上阵数

等级=最多上阵棋子数。花4金买经验可加速升级，等级越高商店出好棋概率越大。

⏱️
战斗规则

每30秒自动战斗。输的一方扣血（扣血=回合数+对方存活棋子数）。血量归0即淘汰！
